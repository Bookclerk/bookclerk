# Web fonts

Copies of the website's Literata and Source Sans 3 files
(`tools/site/src/fonts/`, where their sources and checksums are listed), so
the demo's pages use the same type without loading anything from another
origin. Both are under the SIL Open Font License 1.1 (`OFL-*.txt`).
`test/pages.test.ts` fails when a copy differs from the website's file.
