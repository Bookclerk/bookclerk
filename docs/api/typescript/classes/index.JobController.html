    Class JobController

    Everything one job invocation may touch: the durable envelope, input / output streams, progress(), signal, and the terminal-outcome recorders suspend() / retryLater(). Returning normally without a recorded outcome completes the job; throwing rejects it (unavailable / deadline_exceeded errors are retryable, cancelled is cancelled).
