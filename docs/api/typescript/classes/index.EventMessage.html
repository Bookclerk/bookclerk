    Class EventMessage

    One delivered domain event. Exactly one outcome is recorded per message; the first of ack / retry / reject / deadLetter / suspend wins and later calls are ignored (as with Workers queue messages). Messages left untouched are acked when event() resolves and retried when it throws.
