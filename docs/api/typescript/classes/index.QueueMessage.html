    Class QueueMessage

    One delivered queue message (QueueMessage struct), Workers Message-shaped.

    Exactly one outcome is recorded per message; the first of ack / retry wins and later calls are ignored. Messages left untouched are acked when queue() resolves and retried when it throws.
