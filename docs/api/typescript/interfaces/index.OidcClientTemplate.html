    Interface OidcClientTemplate

    Bookclerk-as-IdP relying-party template. Plugins declare callback path and client id; the host materializes oidc_clients rows and remains the AS. originConfigKey is a dotted config path (e.g. integrations.audiobookshelf.base_url).
