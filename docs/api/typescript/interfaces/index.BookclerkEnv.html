    Interface BookclerkEnv

    Guest env bindings for api_version = 3 manifests. Every host-provided facility is a binding here; there is no HOST object. Bindings appear only when plugin.toml declares them and the operator has consented.

    Run bookclerk-plugin types to generate a precise Env for one manifest (bookclerk-configuration.d.ts), then extends BookclerkEntrypoint<Env>.
