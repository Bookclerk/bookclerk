# Use Bookclerk

This shelf is for people who buy audiobooks and want them in one library
they control. Start with what Bookclerk is, then set it up and connect
your stores.

## Pages on this shelf

- [What is Bookclerk?](what-is-bookclerk.md): what it does, whether it is
  ready, and how to try the demo.
- [Getting started](getting-started.md): install Bookclerk, create your
  account, connect a store and bring in your books.
- [Stores](stores.md): Audible, Libro.fm, Chirp and GraphicAudio.
- [Where your books go](where-books-go.md): folders, cloud storage and
  file names.
- [Discover and wishlist](discover.md): suggestions, catalog search and
  the wishlist.
- [The web app](web-app.md): the screens, roles and ways to sign in.
- [Sharing with your household](sharing.md): invites, what is shared, and
  Audiobookshelf.
- [Join a library as a branch](branches.md): let a second computer help.
- [Coming from Libation](from-libation.md): bring over an existing
  library.
- [Troubleshooting](troubleshooting.md): common problems and fixes.
- [Glossary](glossary.md): the words Bookclerk uses.
