# Contribute

This shelf is for contributors: how to build Bookclerk, how CI checks a
change, and how to write code documentation and docs pages. The
conventions every change follows are in
[`AGENTS.md`](../../AGENTS.md) at the root of the repository.

## Pages on this shelf

- [Build from source and use the CLI](build-from-source.md): build the
  binaries and drive Bookclerk from the command line.
- [Dev Container](devcontainer.md): a ready-made build environment.
- [Web UI development](ui/README.md): the React app, the tray, brand
  assets, and the UI library reference.
- [Continuous integration](ci.md): the planner, the jobs and `CI Gate`.
- [Fuzzing](fuzzing.md): fuzz targets in CI and crash triage.
- [Repository automation](automation.md): dependency updates, advisories,
  docs publishing and Worker deploys.
- [Release packaging](packaging.md): platform bundles and release CI.
- [Code documentation](code-documentation.md): how to document Rust,
  TypeScript, Python and shell.
- [Writing docs](writing-docs.md): how to write a docs page people can
  read quickly.
- [Licensing and the CLA](licensing.md): which license covers what, the
  contributor agreement and the trademark policy.
- [Research notes](research/README.md): store candidates and Libation
  parity.
