# Bookclerk UI

Vite + React + TypeScript library GUI (shadcn-style components, Bookclerk brand).

```bash
npm ci
npm run dev      # proxied to bookclerkd on :8787
npm run build    # writes dist/ for bookclerkd ServeDir
npm run storybook          # component stories on :6006
npm run test:visual        # axe-core + screenshot checks (after storybook:build)
```

See [docs/contributing/ui/README.md](../docs/contributing/ui/README.md) and
[docs/contributing/ui/visual-testing.md](../docs/contributing/ui/visual-testing.md).
