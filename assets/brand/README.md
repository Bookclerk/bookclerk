# Bookclerk production assets

Production exports generated directly from the approved Bookclerk logo and
mark SVG sources.

## Authoritative artwork

- `svg/bookclerk-logo.svg` — horizontal logo with the outlined Literata
  wordmark
- `svg/bookclerk-mark.svg` — standalone application mark

The SVG sources are copied byte-for-byte from the approved files. The wordmark
has already been converted to paths and does not require Literata to be
installed.

## Raster exports

- `png/logo/` — transparent horizontal logo exports at 900 px and 1800 px wide
- `png/mark/` — transparent square mark exports from 16 px through 1024 px

## Web assets

- `web/favicon.ico` — multi-resolution Windows/browser icon
- `web/favicon-16x16.png`
- `web/favicon-32x32.png`
- `web/apple-touch-icon.png` — 180 × 180
- `web/android-chrome-192x192.png`
- `web/android-chrome-512x512.png`
- `web/site.webmanifest`

## Usage

- Prefer the SVG logo for websites, documentation, and scalable interfaces.
- Use the standalone mark for application icons, avatars, and compact layouts.
- Keep the artwork on white, warm-white, or other light backgrounds.
- Do not alter the proportions, path geometry, spacing, or colors.

No monochrome redraw is included because no approved monochrome source was
provided.
